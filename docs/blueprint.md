# **App Name**: Africa Insights Challenge

## Core Features:

- Challenge Generation: AI generates relevant challenge and opportunity scenarios.
- Option Selection: Users select options reflecting their understanding of potential impacts.
- Feedback Display: Provide feedback after each choice to reinforce learning outcomes, and offer explanations via an AI tool when necessary.
- Score Tracking: Tracks scores based on the options selected.
- Leaderboard: A simple local leaderboard sorted by score.

## Style Guidelines:

- Primary color: Warm orange (#F4722B) to reflect the vibrant energy of Africa.
- Background color: Desaturated light orange (#F8D1B7) to create a bright and engaging backdrop.
- Accent color: Teal (#26A69A) to provide contrast and highlight important elements.
- Font: 'PT Sans', a humanist sans-serif font, to ensure readability and maintain a modern feel.
- Use icons to represent different challenges and opportunities in Africa. Simple, clear, and culturally relevant icons are key.
- Clean and intuitive layout with a focus on readability and user-friendliness. Utilize whitespace effectively to avoid overwhelming users with information.
- Subtle transitions and animations to provide feedback to user interactions and create a smooth experience.
